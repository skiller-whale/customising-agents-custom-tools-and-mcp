# Custom Tools and MCP

This repository contains exercises for the SkillerWhale session on Custom Tools and MCP.
It contains two MCP servers.

## Time MCP server

`time_mcp/server.py` is a MCP SDK v2 port of the official [Time MCP server](https://github.com/modelcontextprotocol/servers/tree/main/src/time).

To install requirements:

```sh
python3 -m pip install -r time_mcp/requirements.txt
```

## Customer data MCP server

`customer_mcp/server.py` is a mock-up of a customer data MCP server.
